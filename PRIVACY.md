# Privacy Policy

Effective date: May 28, 2026

## Product

This privacy policy applies to the browser extension "网页小灯——暗色一键切" ("Web Page Lamp").

Web Page Lamp is a lightweight browser extension that lets users show a small lamp button on web pages and switch between normal display mode and dark reading mode.

## Data Collection

Web Page Lamp does not collect, transmit, sell, or share personal data.

The extension does not collect:

- Personal identity information, such as name, address, email address, age, or ID number
- Health information
- Financial or payment information
- Authentication information, such as passwords, credentials, security questions, or PINs
- Personal communications, such as emails, text messages, or chat messages
- Location information, such as GPS location, IP-based location, or device movement information
- Web browsing history
- User activity logs, such as clicks, mouse position, keystrokes, or scrolling behavior
- Website content, such as page text, images, audio, video, links, or form contents

## Local Storage

Web Page Lamp uses browser local storage only to save extension preferences on the user's device.

The locally stored values are:

- The selected lamp mode, such as light mode or dark mode
- Whether the small lamp sidebar should be shown automatically

These values are used only to keep the user's preferred display mode and sidebar visibility consistent across pages and browser sessions.

These values stay on the user's local device. They are not uploaded to any server.

## Website Access

Web Page Lamp can run on ordinary web pages so it can display the lamp button and apply the user's selected dark reading style.

The extension uses page access only for its single purpose: showing the lamp control and changing page appearance locally in the browser.

The extension does not read, store, upload, analyze, or share the contents of web pages.

## Remote Servers

Web Page Lamp does not use remote servers.

The extension does not send data to the developer or to any third party.

The extension does not use analytics, advertising, tracking pixels, telemetry, cloud sync, remote configuration, or remote code.

## Third Parties

Web Page Lamp does not transfer user data to third parties.

Web Page Lamp does not use user data for advertising, personalized advertising, retargeting, credit evaluation, data brokerage, or any unrelated purpose.

## Limited Use Disclosure

The use of information received from Chrome extension APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Any data accessed by the extension is used only to provide or improve the extension's single purpose: local web page light/dark display switching and sidebar visibility control.

## Data Retention and Deletion

Web Page Lamp only stores local preference values in the browser.

Users can delete this local data at any time by:

- Removing the extension from the browser
- Clearing the extension's site and storage data through browser settings

After the extension is removed, the locally stored extension preferences are deleted by the browser.

## Security

Because Web Page Lamp does not transmit user data, user preference data remains on the local device.

The extension code is packaged with the extension and runs locally in the browser. It does not download or execute remote JavaScript or CSS.

## Changes to This Policy

This privacy policy may be updated if the extension's behavior changes.

If the extension adds any data collection, transmission, analytics, cloud sync, account system, or remote service in the future, this policy will be updated before such changes are published.
